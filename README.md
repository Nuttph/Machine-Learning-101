## 🧠 สิ่งที่เรียนรู้ภายในโปรเจคนี้

### 1. **Supervised Learning**

#### 🔹 Classification (การจำแนกประเภท)

ปัญหาที่ผลลัพธ์เป็นหมวดหมู่ เช่น

* การทำนายว่าอีเมลเป็น Spam หรือไม่
* ทำนายโรคจากข้อมูลผู้ป่วย
* ทำนายว่าสินค้าจะขายดีหรือไม่

โมเดลที่ใช้ เช่น Logistic Regression, KNN, Decision Tree, Random Forest, SVM

#### 🔹 Regression (การพยากรณ์ค่าเชิงตัวเลข)

ใช้ทำนายค่าแบบต่อเนื่อง เช่น

* ราคาบ้าน
* คะแนนหรือผลลัพธ์ทางสถิติ

โมเดลที่ใช้ เช่น Linear Regression, Polynomial Regression, Ridge/Lasso Regression

---

### 2. **Unsupervised Learning**

#### 🔹 Clustering (การจัดกลุ่ม)

ใช้แบ่งกลุ่มข้อมูลที่ไม่มี label เช่น

* วิเคราะห์กลุ่มลูกค้า
* แยกประเภทพฤติกรรมผู้ใช้

โมเดลที่ใช้ เช่น K-Means, Hierarchical Clustering, DBSCAN

---

### 3. **หลักการสำคัญอื่น ๆ**

* การเตรียมข้อมูล (Data Preprocessing)
* Feature Scaling / Normalization
* Train/Test Split
* การประเมินผลโมเดล (Evaluation Metrics)
* Overfitting / Underfitting
